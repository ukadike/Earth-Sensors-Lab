# Module 7: Observing Space

Status: proposed (framework drafted; depends on Modules 1–2's observation
and sensor vocabulary, and is the newest addition to the curriculum
sequence — not yet piloted, not yet field-tested)

## Learning goals

- Extend the "observation before devices" habit from Modules 1–2 outward,
  from ground-level environmental sensing to the sky.
- Practice a zero-cost, naked-eye sky observation (a star count) as the
  entry point, before considering any instrument-based sky observation.
- Understand that "space observation" spans a wide range of cost and
  complexity — from counting visible stars to building a radio telescope to
  running code on hardware in orbit — and that low-cost entry points are a
  real, valid form of the same science as expensive instruments.

## Materials

- No equipment required for the core activity (a clear night, a printed or
  described star map, a way to record a count).
- Optional extensions require real external programs, not ESL-built tools —
  see [/research/external-programs.md](../research/external-programs.md)
  for current, verified options (Globe at Night, Radio JOVE, CERN
  TIMEPIX@school, ESA Astro Pi).

## Accessibility notes

- The core activity (counting visible stars against a reference map) is
  inherently visual; no tactile or audio equivalent has been designed yet —
  this is recorded as an `OPEN QUESTION`, not glossed over, in
  [external-programs.md](../research/external-programs.md).
- Where a class includes blind or low-vision students, consider substituting
  or pairing this activity with **listening** for a sky-related signal
  instead of looking for one — Radio JOVE observations (Sun/Jupiter radio
  emissions) are audible, not just visual, and may be a more accessible
  first extension than a star count for some students. This substitution has
  not been tested and is offered as a design direction, not a validated
  accommodation.
- Discussion and reflection portions follow the same plain-language baseline
  as every other module — see [ACCESSIBILITY.md](../ACCESSIBILITY.md).

## Activity

1. On a clear evening, more than an hour after sunset and before moonrise,
   spend ten minutes observing the sky without any instrument — noting
   brightness, color, motion (aircraft vs. stars), and how many stars are
   visible overall.
2. Using a simple reference (a star map showing a few stars of progressively
   fainter magnitude, in the style of the Globe at Night program — see
   [external-programs.md](../research/external-programs.md)), estimate how
   many stars are visible and record it.
3. Compare with a description or account of the same activity done from a
   different location (a darker rural site vs. a brighter urban one, if
   available) — this is where light pollution as an environmental variable
   enters the discussion, connecting back to
   [Module 3](module-03-soil-and-water.md)'s environmental-variable framing.
4. Discuss: is a star count "data" in the same sense as a soil-moisture
   reading? Revisit [what-counts-as-data.md](../research/what-counts-as-data.md).

## Reflection questions

- What made stars easier or harder to see tonight, compared to another
  night or place?
- Is counting stars with your own eyes a form of measurement, observation,
  or both?
- If you wanted to observe something in the sky that your eyes can't detect
  at all (a radio signal, a cosmic ray), what would you need instead of
  eyes?

## Research notes

Investigates: *How can low-cost, hands-on sky-observation tools extend
accessible, community-based science from the ground to the sky?* (Pillar 8,
see [RESEARCH_AGENDA.md](../RESEARCH_AGENDA.md)). This module is
deliberately the newest and least developed in the sequence — it exists to
open the question, not answer it, and to connect Earth Sensors Lab's
existing observation-first philosophy to real external programs rather than
inventing new space-observation tools of its own.

## Teacher adaptation notes

- This module can run as a single at-home or take-home observation (assign
  the star count as homework on a clear night) rather than requiring
  synchronized classroom time — useful where the class can't gather after
  dark together.
- For a class ready to go further, treat this module as a launch point into
  one of the real external programs in
  [/research/external-programs.md](../research/external-programs.md) —
  Globe at Night for a direct continuation of the star-count activity;
  Radio JOVE or CERN's TIMEPIX@school for a bigger, multi-week commitment;
  ESA Astro Pi for a class with coding experience and existing
  Raspberry Pi familiarity from
  [module-02-sensors.md](module-02-sensors.md) and
  [/hardware/raspberry-pi-guide.md](../hardware/raspberry-pi-guide.md).
- Always check the live program page for current deadlines before
  committing a class — see the caveat at the top of
  [external-programs.md](../research/external-programs.md).
