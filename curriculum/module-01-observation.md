# Module 1: Observation Before Measurement

Status: in development (draft curriculum, not yet field-tested)

## Learning goals

- Distinguish careful, unaided observation from measurement.
- Practice describing an environment (a garden bed, a windowsill, a
  schoolyard corner) using multiple senses before introducing any tool.
- Build the habit of noticing before quantifying — a foundation for every
  later module.

## Materials

- A notebook or the printable [student-workbook.md](student-workbook.md)
  observation page.
- No sensors or electronic tools required for this module.
- Optional: hand lens, for closer visual observation.

## Accessibility notes

- Observation is framed multisensorially from the start — touch, sound,
  smell, sight — so blind and low-vision students are not retrofitted into a
  visually-designed activity. See
  [blind-low-vision-mode.md](../accessibility/blind-low-vision-mode.md).
- The workbook page is available in a plain-text, screen-reader-friendly
  format and a high-contrast printable format.

## Activity

1. Choose a small, consistent observation site (a garden bed, a plant, a
   patch of ground).
2. Spend five uninterrupted minutes observing with as many senses as
   available and safe (sight, sound, smell, touch).
3. Record observations in plain descriptive language — no numbers or
   measurements yet.
4. Repeat at a different time of day or after a change in weather, and
   compare.

## Reflection questions

- What did you notice that you might have missed with a quick glance?
- What would be hard to describe in words but easy to point to or touch?
- What questions do your observations raise that a measurement might help
  answer?

## Research notes

Investigates: *How can students learn environmental science through
low-cost sensors?* — by establishing observation as the baseline this module
sequence measures sensor-supported learning against. No sensor is
introduced in this module by design, so later modules can compare
sensor-supported observation to this baseline.

## Teacher adaptation notes

- Works outdoors or with a single potted plant indoors.
- For mixed-ability classrooms, pair students so sensory observations can be
  shared and described collaboratively.
- Can be shortened to a single sense (e.g., sound only) as an accessible
  variant without losing the core goal.
