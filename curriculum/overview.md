# Curriculum Overview

Earth Sensors Lab curriculum is organized as eight thematic modules, sharing
six documented module files (two files each cover two closely related
themes). Every module is designed to work with or without a physical sensor
kit, and with or without reliable internet access.

## Design principles

- **Observation before measurement.** Every module sequence starts with
  unaided, sensory observation before introducing instruments.
- **Accessible by default**, not adapted afterward — see
  [ACCESSIBILITY.md](../ACCESSIBILITY.md).
- **Modular** — a teacher can run one module independently; modules do not
  strictly require each other, though they build in suggested order.
- **Research-linked** — every module names the research question(s) it
  investigates (see [research notes](../research/research-questions.md)).
- **Honest about status** — modules are draft/`in development` curriculum,
  not field-tested lesson plans, until a pilot (see
  [PILOT_MODEL.md](../PILOT_MODEL.md)) has actually run them.
