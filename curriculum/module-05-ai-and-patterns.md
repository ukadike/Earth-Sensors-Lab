# Module 5: AI as Pattern Assistant

Status: in development (draft curriculum, not yet field-tested)

## Learning goals

- Understand what a rule-based or AI-supported tool can plausibly help with
  when looking at environmental data (noticing patterns, flagging anomalies,
  offering plain-language summaries).
- Understand what such a tool should not be trusted to do (make final
  judgments, replace teacher assessment, substitute for a student's own
  reasoning).
- Practice treating an AI-generated observation as a prompt for further
  thinking, not a finished answer.

## Materials

- [AI Reflection Assistant concept](../software/ai-reflection-assistant.md),
  where available as a working prototype; otherwise, a printed set of
  example AI-style pattern flags for classroom discussion.
- Data collected in Modules 3–4, or sample data sets.

## Accessibility notes

- Any AI tool used must disclose plainly that it is AI-assisted, per
  [ETHICS_AND_CONSENT.md](../ETHICS_AND_CONSENT.md) "AI transparency."
- AI-generated text output should meet the same plain-language and
  screen-reader accessibility baseline as any other classroom material — see
  [ACCESSIBILITY.md](../ACCESSIBILITY.md).

## Activity

1. Review a data trend from an earlier module.
2. If a working AI Reflection Assistant prototype is available, have it
   generate a plain-language observation or flag about the trend. If not,
   review a provided example output for discussion instead.
3. As a class, evaluate: is this observation accurate? What is it missing?
   What would a person notice that it didn't?
4. Discuss the "do not overclaim" rule from
   [SSL-METHOD.md](../SSL-METHOD.md) in the context of AI-generated
   observations specifically.

## Reflection questions

- What did the tool notice that you might have missed?
- What did the tool get wrong, oversimplify, or miss entirely?
- Whose judgment should be final when the tool and a person disagree?

## Research notes

Investigates: *How can AI support student reflection without replacing
teacher judgment?* This module is the primary curricular test bed for that
question and is explicitly designed to model critical evaluation of AI
output, not uncritical use of it.

## Teacher adaptation notes

- Can be run with no AI tool at all, using provided example outputs, if no
  working prototype exists at the site yet — this is the expected case
  currently, since the AI Reflection Assistant is concept-stage (see
  [PROTOTYPES.md](../PROTOTYPES.md)).
- Emphasize to students throughout that the tool is a prompt for their own
  thinking, not an authority.
