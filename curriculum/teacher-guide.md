# Teacher Guide

Cross-module guidance for educators running Earth Sensors Lab curriculum.
This guide assumes no prior sensor or hardware experience.

## Before you start

- Read [CURRICULUM.md](../CURRICULUM.md) for the module map and
  [ACCESSIBILITY.md](../ACCESSIBILITY.md) for the accessibility baseline
  every module should meet.
- You do not need a physical sensor kit to begin — Modules 1, 2, 5, and 6 can
  run with no hardware at all; Modules 3 and 4 are easier with one but have
  low-tech substitutes noted in each module.
- If you're considering an ongoing partnership (not just a one-off lesson),
  see [PARTNERSHIP_MODEL.md](../PARTNERSHIP_MODEL.md) and
  [PILOT_MODEL.md](../PILOT_MODEL.md) before committing a class's time.

## Adapting for mixed-ability classrooms

- Every module's "accessibility notes" section names specific
  accommodations; treat these as starting points, not exhaustive lists.
- Pair sighted and blind/low-vision students for shared sensory observation
  rather than separating accommodation as a parallel track.
- Printable, low-ink versions of all workbook pages are available via
  [student-workbook.md](student-workbook.md).

## Using this as light research participation

Running these modules and sharing what happened (through the process in
[PILOT_MODEL.md](../PILOT_MODEL.md) and
[/research/findings-template.md](../research/findings-template.md)) is itself
a contribution to the [research agenda](../RESEARCH_AGENDA.md). You do not
need to run a formal study to contribute — informal classroom notes,
submitted through GitHub Issues, are welcome and valuable.

## What this guide does not promise

- No module has been field-tested in a real classroom as of this writing.
  Treat all activities as draft curriculum to be adapted, not a proven
  lesson plan.
- No specific timing (minutes/class periods) is prescribed here, since that
  depends heavily on class size, age group, and site — teachers should adapt
  freely and are encouraged to share what worked.
