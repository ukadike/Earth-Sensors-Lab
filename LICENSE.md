## Source code — license TBD

No functioning source code exists in this repository yet — hardware and
software areas (see [PROTOTYPES.md](PROTOTYPES.md)) are documentation-only
concepts. A license for future source code (firmware, dashboard code,
visualization scripts, schema-validation tooling) has not yet been decided
and is marked `OPEN QUESTION` here.

JSON Schema files in [/schemas/](schemas/) are treated as documentation
(covered by CC BY 4.0 above) rather than executable source code, since they
describe data shape rather than implement behavior.

When real source code is added to this repository, this section will be
updated with a specific license (for example, MIT or Apache 2.0) before or
alongside that code's addition — not retroactively assumed.

## Visual system

`variables.css` and `site.css` implement a visual-language token system
shared across Small Systems Lab, Echo, Omoluabi, and Umada, and are locked
per [CLAUDE.md](CLAUDE.md). They are covered by CC BY 4.0 as written content
per above; reuse across the sibling repositories listed is intentional and
already occurring.
