# Curriculum

Earth Sensors Lab curriculum is modular, research-linked, and designed to
work with or without internet access, in classrooms, gardens, museums, and
libraries.

Curriculum is a research artifact here, not a finished product: each module
is expected to be adapted, critiqued, and revised as pilots generate
evidence. See [CURRICULUM.md](CURRICULUM.md) status labels and
[/curriculum/overview.md](curriculum/overview.md) for the current state of
each module.

## How curriculum connects to research

Each module's "research notes" section names the
[research question(s)](RESEARCH_AGENDA.md) it investigates. Evidence from
running a module in a real classroom or site is recorded through the pilot
process in [PILOT_MODEL.md](PILOT_MODEL.md), not asserted in the module
itself.

## Accessibility

All modules follow the baseline in [ACCESSIBILITY.md](ACCESSIBILITY.md):
plain-language activity text, tactile/sonic alternatives noted per module,
and printable low-ink versions. See
[/accessibility/tactile-learning.md](accessibility/tactile-learning.md) and
[/accessibility/sonification.md](accessibility/sonification.md) for the
underlying design guidance each module draws on.
