# Roadmap

Earth Sensors Lab develops in five phases. Phase 1 is substantially complete
as of this pass; later phases are `proposed` or `in development` unless noted.

## Phase 1 — Repository Foundation

- README
- research agenda
- partnership model
- accessibility baseline
- schema cards

**Status:** complete as documentation. See [README.md](README.md),
[RESEARCH_AGENDA.md](RESEARCH_AGENDA.md),
[PARTNERSHIP_MODEL.md](PARTNERSHIP_MODEL.md),
[ACCESSIBILITY.md](ACCESSIBILITY.md), [SCHEMA_CARD.md](SCHEMA_CARD.md).

## Phase 2 — Prototype Documentation

- hardware kit
- software concepts
- p5 visualization
- curriculum modules

**Status:** in development. See [/hardware/](hardware/), [/software/](software/),
[CURRICULUM.md](CURRICULUM.md). All documentation-only at this stage — no
working code or tested hardware builds yet.

## Phase 3 — Pilot Readiness

- school pilot template
- university partner note
- ethics and consent
- evaluation plan

**Status:** in development. See [PILOT_MODEL.md](PILOT_MODEL.md),
[ETHICS_AND_CONSENT.md](ETHICS_AND_CONSENT.md), [/pilots/](pilots/),
[/research/pilot-evaluation.md](research/pilot-evaluation.md).

## Phase 4 — Funding Readiness

- grant language
- one-page summary
- budget notes
- partnership packet

**Status:** proposed. Grant language and one-page summary drafted in
[/docs/grant-language.md](docs/grant-language.md) and
[/docs/one-page-summary.md](docs/one-page-summary.md). Budget notes and a
full partnership packet are `AWAITING FRAGMENT` — no budget figures exist yet
to document.

## Phase 5 — Open Toolkit

- reusable curriculum
- downloadable sensor kit guide
- accessible dashboard prototype
- community observatory template

**Status:** proposed. Depends on Phases 2–4 producing tested, field-validated
material before anything is packaged as a reusable toolkit.

## How this roadmap is used

Phases are sequential in emphasis but not strictly gated — accessibility and
research-agenda work (Phase 1) continues throughout. No phase is marked
complete until its listed deliverables exist as real files in this
repository; this roadmap is updated as that happens, not in advance of it.
