# Partnership Note: NYU

## Status

`AWAITING FRAGMENT` — no signed or confirmed partnership agreement between
Earth Sensors Lab and NYU (or any specific NYU program, such as ITP/IMA or
ICP) exists in this repository as of this writing. This file is an index
entry for that possibility, not a description of an active partnership.

## Why this note exists

This repository's brief calls for the site to be immediately understandable
to NYU / ITP / IMA / ICP collaborators specifically, given the fit between
Earth Sensors Lab's creative-technology and accessibility focus and those
programs' work. This note exists so a university research partnership, if
and when one is formed, has a clear place to be documented — per the
university research partner type in
[PARTNERSHIP_MODEL.md](../PARTNERSHIP_MODEL.md).

## What a university research partnership would involve

Per [PARTNERSHIP_MODEL.md](../PARTNERSHIP_MODEL.md) and
[PILOT_MODEL.md](../PILOT_MODEL.md): research design support, evaluation
capacity, institutional review (IRB where applicable — see
[/research/study-protocols.md](../research/study-protocols.md)), and student
researcher involvement, in exchange for field sites, co-published findings,
and access to prototype testbeds documented in [PROTOTYPES.md](../PROTOTYPES.md).
