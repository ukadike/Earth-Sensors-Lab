# School Pilot Template

A template for structuring a school pilot partnership. Copy this into a new,
site-specific file when a real pilot is being planned — do not fill in
hypothetical details here.

```markdown
# School Pilot: [School Name]

Status: proposed | in development | pilot | closed

## Fit and framing
- Research question(s) this pilot investigates: [link to research-questions.md]
- Funding source: [grant / fellowship / sponsor / in-kind — named once confirmed]
- Confirmed non-fee-for-service framing shared with school: [yes/no, date]

## Consent and ethics
- School consent obtained: [date]
- Parent/guardian consent process: [description]
- Photo/video consent (if applicable): [description]
- Accessibility accommodations identified: [list]

## Design
- Prototype(s) / curriculum module(s) used: [links]
- Duration: [dates]
- Number of students / classes involved: [count]

## Implementation notes
- [Ongoing log of what actually happened, dated entries]

## Evaluation
- See /research/pilot-evaluation.md framework
- Findings recorded at: [link to dated findings file, once written]

## Continuation or close
- Outcome: [continuing / expanded / closed, with brief reasoning]
```

## Notes on using this template

- Every section should be filled with real information only — leave a
  section as `AWAITING FRAGMENT` rather than inventing plausible-sounding
  content.
- See [ETHICS_AND_CONSENT.md](../ETHICS_AND_CONSENT.md) and
  [PILOT_MODEL.md](../PILOT_MODEL.md) for the full rules this template
  implements.
