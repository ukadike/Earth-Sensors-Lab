# Museum / Library Pilot Template

A template for structuring a museum or library pilot partnership. Copy this
into a new, site-specific file when a real pilot is being planned — do not
fill in hypothetical details here.

```markdown
# Museum/Library Pilot: [Institution Name]

Status: proposed | in development | pilot | closed

## Fit and framing
- Research question(s) this pilot investigates: [link to research-questions.md]
- Public-facing context (exhibit, program, drop-in space): [description]
- Funding source: [grant / fellowship / sponsor / in-kind]

## Consent and ethics
- Institutional agreement: [date]
- Visitor consent process (for any data collection involving visitors): [description]
- Accessibility accommodations identified: [list, referencing ACCESSIBILITY.md]

## Design
- Prototype(s) / curriculum module(s) used: [links]
- Public exhibit or program format: [description]
- Duration: [dates]

## Implementation notes
- [Ongoing log of what actually happened, dated entries]

## Evaluation
- See /research/pilot-evaluation.md framework
- Findings recorded at: [link, once written]

## Continuation or close
- Outcome: [continuing / expanded / closed]
```

## Notes specific to museum/library contexts

- Museum and library sites typically involve public, drop-in visitors rather
  than an enrolled classroom — consent processes should reflect that (e.g.,
  posted notices plus opt-in participation, rather than a school's
  parent/guardian consent flow) per
  [ETHICS_AND_CONSENT.md](../ETHICS_AND_CONSENT.md).
- Exhibit materials should meet the same accessibility baseline in
  [ACCESSIBILITY.md](../ACCESSIBILITY.md), including physical/tactile
  accommodations relevant to a public exhibit space.
