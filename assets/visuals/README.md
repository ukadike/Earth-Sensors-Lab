# Earth Sensors Lab Visual Assets

The public GitHub Pages site references the visual assets in this directory.

## Current figures

- `visual-01-observatory.webp` — whole-system observatory concept
- `visual-02-soil-station.webp` — student-built soil sensing station
- `visual-03-soil-system-architecture.webp` — conceptual system architecture
- `visual-04-soil-exploded-assembly.webp` — exploded physical assembly
- `visual-05-soil-wiring-signal-map.webp` — proposed/pre-build wiring and signal map

Each figure has concise alt text and a caption on the public site. Full long descriptions and technical-status notes are in [`docs/VISUALS.md`](../../docs/VISUALS.md).

If a figure fails to render on GitHub Pages, use the raw GitHub asset URL listed in the HTML source as the canonical fallback. The figure text documentation remains authoritative even when an image does not load.
