# Temperature / Humidity Sensor

Prototype documentation for the temperature and humidity component of the
sensor kit (see [sensor-kit-overview.md](sensor-kit-overview.md)).

## What it measures

Ambient air temperature and relative humidity, typically from a single
combined digital sensor module.

## Why combined

A single combined sensor reduces wiring complexity and cost versus separate
temperature and humidity components — appropriate for a classroom-scale kit
where simplicity of assembly matters as much as precision.

## Classroom / curriculum use

Primary hardware reference for
[module-03-soil-and-water.md](../curriculum/module-03-soil-and-water.md),
alongside soil moisture (see [soil-moisture.md](soil-moisture.md)).

## Placement notes

- Should be shielded from direct sun to avoid skewed temperature readings —
  specific shielding/housing design is `OPEN QUESTION`, tied to the broader
  enclosure question in [sensor-kit-overview.md](sensor-kit-overview.md).
- Indoor and outdoor placements will read differently for the same "site" —
  curriculum should make this comparison explicit rather than treat one
  reading as universally representative.

## Accessibility notes

Same as soil moisture: spoken/numeric and, where available, tactile output.
See [/accessibility/tactile-learning.md](../accessibility/tactile-learning.md).
