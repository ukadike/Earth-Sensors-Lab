# Visual Language

Earth Sensors Lab's visual language should feel observational, scientific,
warm, accessible, field-notebook inspired, garden/lab hybrid, tactile,
modular, calm, and trustworthy.

## Building blocks

- **Cards** — modular content units, already used structurally throughout
  this repository's Markdown (schema cards, module cards) and in
  `index.html`'s `.card` elements.
- **Diagrams** — for sensor placement, data flow, and observatory layout, as
  hardware and software concepts mature past documentation-only stage.
- **Field notes** — plain, dated, observational prose style, modeled by this
  repository's own audit and case-note documents.
- **Sensor maps** — site-level maps showing sensor placement, for community
  observatory and pilot documentation.
- **Timelines** — for showing data trends over time (see
  [/software/p5-visualizations.md](../software/p5-visualizations.md)) and for
  the [ROADMAP.md](../ROADMAP.md) phases.
- **Accessible charts** — see
  [/accessibility/wcag-checklist.md](../accessibility/wcag-checklist.md) and
  [/software/prototype-dashboard.md](../software/prototype-dashboard.md).
- **Simple icons** — used sparingly, always paired with text labels (no
  icon-only meaning).
- **High-contrast palettes** — required baseline, not optional theme.
- **Printable layouts** — every digital material should have a printable,
  low-ink equivalent.

## Locked visual system

The actual color/type tokens are locked in `variables.css`, shared across
Small Systems Lab, Echo, Omoluabi, and Umada — see
[CLAUDE.md](../CLAUDE.md). This document describes the *feel* the visual
language should achieve within those locked tokens, not a proposal to change
them.

## What to avoid

- Decorative-only icons or illustrations with no functional or informational
  role.
- Visual metaphors that read as a children's craft project rather than a
  research lab — see the tone rules in [CLAUDE.md](../CLAUDE.md).
- Any visual element whose meaning depends on color alone.

## Status

Descriptive guidance for future diagrams, exhibit materials, and any new
visual assets. No new visual assets have been added to this repository as
part of this pass beyond the existing `index.html`/`site.css`/`variables.css`
system.
