# FAQ

## Is Earth Sensors Lab a paid enrichment program?

No. Earth Sensors Lab is a nonprofit/public-interest research initiative. It
is not primarily a fee-for-service vendor. See
[PARTNERSHIP_MODEL.md](../PARTNERSHIP_MODEL.md) and the case note that
prompted this clarification,
[/pilots/pentaville-case-note.md](../pilots/pentaville-case-note.md).

## How is Earth Sensors Lab funded?

Through grants, fellowships, universities, foundations, sponsors, public
agencies, and philanthropic partners — not tuition or per-student fees. See
[/docs/grant-language.md](grant-language.md).

## Can our school/museum/library/garden participate?

Possibly, as a pilot or research partner. See
[PARTNERSHIP_MODEL.md](../PARTNERSHIP_MODEL.md) for partner types and
[PILOT_MODEL.md](../PILOT_MODEL.md) for how a pilot works, phase by phase.

## Is there a working sensor kit or app we can use today?

Not yet. Everything in [/hardware/](../hardware/) and
[/software/](../software/) is prototype or concept-stage documentation — see
[PROTOTYPES.md](../PROTOTYPES.md) for exact status per item. No finished
hardware or software product currently exists.

## What ages or grade levels is the curriculum for?

Not yet specified by age/grade — the curriculum in
[CURRICULUM.md](../CURRICULUM.md) is written to be adaptable, and specific
grade-level guidance is `OPEN QUESTION` pending real classroom piloting and
teacher feedback (see [teacher-guide.md](../curriculum/teacher-guide.md)).

## How does Earth Sensors Lab handle student data and privacy?

See [ETHICS_AND_CONSENT.md](../ETHICS_AND_CONSENT.md) in full — data
minimization, explicit consent processes, and no student is identified by
name in any public output.

## How does AI get used in this lab?

As a rule-based, transparent reflection support tool — not for grading and
not as a replacement for teacher judgment. See
[/software/ai-reflection-assistant.md](../software/ai-reflection-assistant.md)
and [ETHICS_AND_CONSENT.md](../ETHICS_AND_CONSENT.md) "AI transparency."

## Is this repository open source?

Written content (documentation, curriculum, research notes) is licensed
under CC BY 4.0. Source code license is not yet decided, since no working
code exists in this repository yet. See [LICENSE.md](../LICENSE.md).

## How can I contribute?

See [CONTRIBUTING.md](../CONTRIBUTING.md). All contribution and feedback
happens through GitHub Issues:
<https://github.com/ukadike/Earth-Sensors-Lab/issues>

## What is Earth Sensors Lab's relationship to Small Systems Lab?

Earth Sensors Lab is one research branch of
[Small Systems Lab](https://ukadike.github.io/Small-Systems-Lab/), applying
its method (Operations of Care, Rule-Based Intelligence, Ancient Geometry,
Accessibility as System Architecture) to environmental sensing and STEAM
education specifically. See [SSL-METHOD.md](../SSL-METHOD.md).
